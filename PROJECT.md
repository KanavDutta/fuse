# Song Fusion Studio

An app for turning musical references and creative direction into an original song project.

## Core workflow

1. Enter two reference tracks (title and artist), with an optional third.
2. Describe the qualities to draw from each: groove, energy, instrumentation, mood, or arrangement.
3. Choose a genre hybrid, tempo, mood, drums, melodic instruments, and vocal treatment.
4. Generate a song project and refine individual sections.
5. Copy or download the result, including concise style tags and a complete prompt for an audio generator.

Reference names provide context. Track analysis requires a separately implemented audio or metadata integration; entering a title alone must not be presented as listening to a track.

## Songwriting output

- Original title and creative concept.
- Lyrics organized into Intro, Verse 1, Pre-Chorus, Chorus, Verse 2, Chorus, Bridge, Guitar/Synth Solo, Final Chorus, and Outro.
- Suggested key, tempo, meter, and chord progressions.
- Arrangement notes and transitions for every section.
- Instrumentation, vocal direction, and mixing notes.
- Short genre/style tags and a full audio-generation prompt.

Lyrics and melodies must be original. Reference tracks guide broad musical characteristics without copying lyrics or recognizable melodies. Production notes describe a target sound; they do not certify broadcast-ready audio.

## Interface

A studio workspace with reference-track cards, creative controls, and an editable song output. Keep reference influence and output sections visible and easy to revise. Include input validation, clear generation status, actionable errors, copy/export actions, and saved local drafts.

## Implementation boundary

The selected product scope is finished-song audio generation and playback. The user requested building the app first and connecting audio later. The current local version implements recipe creation, browser-local saving, prompt export, a manually editable ten-section songwriting workspace, and imported-audio playback. Song notes are stored with local drafts and recipes and support copy/text export. No lyrics, musical notes, or audio are generated by a model. Provider-backed generation is explicitly unavailable until that later integration.

Real text generation needs a server-side model integration with credentials stored outside browser code. Finished audio additionally needs a music-generation provider with an available API, job status handling, playback, and downloads. Neither service should be simulated as a successful AI generation.

Do not assume reference audio ingestion, streaming-service access, voice cloning, accounts, billing, or public sharing in the first release.

## Acceptance criteria

- Two required reference tracks and an optional third can be entered.
- All creative controls are reflected in the generation request.
- Generated text is editable and can be copied or exported.
- The specified song structure is preserved.
- Missing integration credentials and failed requests produce clear errors.
- If audio generation is selected, users can follow job progress and play/download the completed result.
- Layout works on desktop and mobile, with labeled keyboard-accessible controls.

## Imported-audio mixing

The app additionally supports local DSP mixing of two imported songs or prepared stems. It estimates BPM, accepts manual cue alignment, optionally matches speed with a pitch change, applies bass EQ and RMS gain balancing, and renders equal-power blends or DJ transitions to a downloadable stereo WAV. Peak attenuation prevents PCM clipping. Audio generation remains disconnected. Source files/results are session-only and independent of saved songwriting recipes. Model-based stem separation, key matching, automatic downbeat grids, pitch-preserving time stretching, and LUFS measurement remain future work.

## Optional ElevenLabs integration

The server now supports explicit, reviewed ElevenLabs Music requests when ELEVENLABS_API_KEY is configured in a private .env file. It validates prompts and durations, stores job status and audio locally, supports cancellation and generated MP3 playback/download, and refuses remote generation access. The default without a key remains disconnected. Music account access and a real paid generation have not yet been verified; test responses are injected only in automated tests.

## Local generation implementation

ACE-Step 1.5 turbo is installed privately under ignored data/local-ai. Low-memory GPU generation is connected through the loopback API, with optional LM disabled, CPU offloading, tiled decoding, eight inference steps, and single-task execution. Local mode supports instrumentals up to 30 seconds; it never falls back to ElevenLabs. See docs/LOCAL-GENERATION.md for startup and measured validation.
